# Gmail-Add-on-Malicious-Email-Scorer
A professional Gmail Add-on &amp; Python backend (Cloud Run) detecting phishing and domain spoofing in real-time.  Key Features:  Modular engine with dynamic check discovery.  Malicious URL scanning via URLHaus.  Secure architecture using GCP Secret Manager.  Stack: Python, Flask, Docker, Apps Script, GCP.  v1.0 Stable
